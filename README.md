## 📖 How to Use - Pro Version

### Upload Designs (Batch Upload)
1. Click **"Upload Designs"** button (top right)
2. OR drag & drop multiple files onto the upload zone
3. Supports: PNG, JPG, SVG formats
4. Upload as many designs as you want!

### View Your Design Library
- All uploaded designs appear in grid view
- Click any design to select it (✓ Selected badge appears)
- Use **"Select All"** to select everything
- Hover over designs to see Edit/Delete buttons

### Generate Mockups Automatically
1. Select one or more designs from your library
2. Click **"Generate Mockups"** button
3. Automatically creates 6 variations per design:
   - T-Shirt Front
   - T-Shirt Back
   - T-Shirt Folded
   - Hoodie Front
   - Hoodie Back
   - Hoodie Folded

### View Variations
1. Click **"Variations"** in sidebar (or it opens automatically)
2. See all generated mockups in grid view
3. Each shows live preview of the mockup
4. Individual Edit/Export buttons on each variation

### Edit Individual Mockups
1. Click **"Editor"** in sidebar
2. OR click **"Edit"** on any variation
3. Use the controls:
   - **Product Type**: Choose T-Shirt or Hoodie
   - **View**: Front, Back, or Folded
   - **Size Slider**: 10% to 200%
   - **Rotation Slider**: 0° to 360°
   - **Position**: Drag design on canvas OR use X/Y inputs
   - **Text Overlay**: Add product names/descriptions

### Batch Export
1. Click **"Batch Export"** in sidebar
2. Choose settings:
   - **Format**: PNG or JPG
   - **Resolution**: 1x, 2x, 3x, or 4x (3x = 2400×3000px)
   - **Include text overlays**: Yes/No
3. Click **"Export All Variations"** (exports everything)
4. OR **"Export Selected Only"** (exports only selected designs)
5. Watch progress bar as files download!

## 🎯 Example Workflow

### Creating Mockups for 5 Designs:

1. **Upload** (30 seconds)
   - Drag & drop 5 design files
   - Files appear in Design Library

2. **Select** (5 seconds)
   - Click "Select All" button

3. **Generate** (2 seconds)
   - Click "Generate Mockups"
   - Creates 30 variations (5 designs × 6 mockups)

4. **Review** (1 minute)
   - Browse Variations page
   - See all 30 mockups with previews

5. **Export** (30 seconds)
   - Go to Batch Export
   - Choose 3x resolution
   - Click "Export All Variations"
   - 30 high-res PNG files download automatically!

**Total Time: ~2 minutes for 30 professional mockups!**

## 💡 Pro Tips

### For Best Results:
1. **Use transparent PNG files** for designs
2. **Design size**: 3000×3000px or larger for best quality
3. **Export at 3x or 4x** for print-ready quality
4. **Keep designs centered** on the mockup templates
5. **Use text overlays** to add product names for client presentations

### Workflow Tips:
- Upload all designs at once (batch upload)
- Use "Select All" for quick variation generation
- Edit individual variations if needed
- Export everything at once with batch export
- Save exported mockups organized by design name

### Performance Tips:
- Works best with Chrome or Firefox
- For 100+ designs, generate in batches
- Export progress shows status for large batches
- Mobile works best with 10-20 designs at a time

## 🔧 Troubleshooting

### File Won't Open
**Problem:** Double-clicking doesn't work
**Solution:** Right-click → Open With → Choose Browser

### Designs Not Loading
**Problem:** Upload seems stuck
**Solution:**
- Try smaller file sizes (under 5MB each)
- Use PNG/JPG instead of very large files
- Refresh browser and try again

### Export Not Working
**Problem:** Download doesn't start
**Solution:**
- Check browser popup blocker settings
- Allow downloads from local files
- Try exporting one at a time first

### Canvas Not Showing
**Problem:** Blank canvas area
**Solution:**
- Refresh the page
- Try a different browser (Chrome recommended)
- Make sure JavaScript is enabled

### Mobile Issues
**Problem:** Interface looks wrong on phone
**Solution:**
- Rotate to landscape mode for better view
- Use Pro version (better mobile support)
- Pinch to zoom if needed
